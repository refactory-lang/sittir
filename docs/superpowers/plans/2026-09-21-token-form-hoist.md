# Token Form Hoist Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every whole-rule token whose body holds an alternation of forms becomes a supertype over one minted token kind per form, with interior enums stored as text.

**Architecture:** A pure distribution function in the DSL transform layer turns `token(seq(P, choice(A, B), S))` into `choice(token(seq(P, A, S)), token(seq(P, B, S)))`. Enrich, which already mints every sittir-synthesized kind and runs in both pipelines, applies it to every rule body, mints each arm through its existing `arm` naming or the name `variant()` stamped on the rule, and adds the rule to the grammar's supertypes. Transform only stamps the names; it no longer hoists. The emitters' storage classifier stops handing kind ids to slots inside a lexed compound: an interior enum is `verbatim` storage carrying its spellings, which the types, factory, coercer, wrap and transport emitters already know how to carry as text.

**Tech Stack:** TypeScript (ESM, `.ts` imports), vitest, tree-sitter CLI through `sittir gen`, Rust render crates regenerated by codegen.

**Spec:** `docs/superpowers/specs/2026-09-21-token-form-hoist-design.md`

## Global Constraints

- Only whole-rule tokens hoist. A `token(...)` embedded inside a larger rule body, and a token whose only alternations are presence or spelling, are left untouched (spec: "The outermost form alternation of a whole-rule token hoists").
- Outermost only: the first form alternation on each path from the token root hoists; a form alternation nested inside an arm stays in that arm's lexeme (spec: same section).
- Minted arm names come from the mint taxonomy: `<rule>_arm` when one arm is minted, `<rule>_arm<N>` (N from 1, in arm order) when several are (spec: "Each arm mints as `<rule>_arm` or `<rule>_armN`").
- `variant()` on a hoisted arm is a rename; variant paths address the arms after distribution, by top-level index (spec: "`variant()` on a hoisted arm is a rename and nothing else").
- Hazards are compile-time diagnostics naming the rule and arms: an arm that matches the empty string, or two arms with identical bodies (spec: "Why it lexes the same").
- Nothing inside a lexeme has a kind id: an interior enum is text-stored and typed as the union of its spellings; an interior flag is a boolean. Rust's `integer_literal.suffix` moves with it (spec: "Nothing inside a lexeme has a kind id").
- No comments in `packages/codegen/src/`; every new or changed function gets a `docs/glossary/<dir>.md` entry keyed by qualified name.
- Generated outputs (`packages/<g>/src/*`, `packages/<g>/.sittir/*`, `rust/crates/sittir-<g>/src/*`) are never hand-edited. Any edit under `packages/codegen/src/**` stales the three manifests; regenerate all three grammars and commit the manifests with the source. Never `--no-verify`.
- Commit with a pathspec (`git commit -- <paths>`); the working tree carries unrelated speckit noise. Do not run `oxfmt` on `packages/codegen/src/emitters/test.ts` or `overlays/polymorphs.ts`; the committed versions are not formatter-clean and it adds rewrap noise.
- Run vitest as its own Bash call, never chained after a regen.
- Gates before the final push: `pnpm run type-check`, `pnpm run lint` (the six pre-existing errors under `.specify/extensions/security-review/` are not ours), the targeted vitest files, `pnpm run validate:native` followed by `pnpm run validate:history` with numbers compared against the previous rows, and the generated node suites for every regenerated grammar.

```ts
import { classifyTokenChoice, distributeTokenForms } from '../transform/token-forms.ts';
import type { RuntimeRule } from '../../types/runtime-shapes.ts';

const P = (value: string) => ({ type: 'PATTERN', value }) as unknown as RuntimeRule;
const BLANK = { type: 'BLANK' } as unknown as RuntimeRule;

const choice = (...members: RuntimeRule[]) => ({ type: 'CHOICE', members }) as unknown as RuntimeRule;
const token = (content: RuntimeRule) => ({ type: 'TOKEN', content }) as unknown as RuntimeRule;
const immediate = (content: RuntimeRule) => ({ type: 'IMMEDIATE_TOKEN', content }) as unknown as RuntimeRule;
const prec = (value: number, content: RuntimeRule) => ({ type: 'PREC', value, content }) as unknown as RuntimeRule;
const shape = (r: RuntimeRule): unknown => JSON.parse(JSON.stringify(r));

describe('classifyTokenChoice', () => {
	it('a choice with a blank arm is presence', () => {
		expect(classifyTokenChoice(choice(seq(S('e'), P('\\d+')), BLANK))).toBe('presence');
	});
	it('a choice of string literals is spelling', () => {
		expect(classifyTokenChoice(choice(S('0x'), S('0X')))).toBe('spelling');
	});
	it('two or more non-blank arms with a non-literal among them are forms', () => {
		expect(classifyTokenChoice(choice(seq(S('0x'), P('[0-9a-f]+')), P('\\d+')))).toBe('forms');
	});
});

describe('distributeTokenForms', () => {
	it('leaves a rule alone when its body is not a token', () => {
		const rule = seq(S('a'), choice(P('x'), P('y')));
		expect(distributeTokenForms(rule, 'demo')).toBe(rule);
	});
	it('leaves a token alone when it holds only spelling and presence choices', () => {
		const rule = token(seq(choice(S('0x'), S('0X')), P('[0-9]+'), choice(S('n'), BLANK)));
		expect(distributeTokenForms(rule, 'demo')).toBe(rule);
	});
	it('hoists a top-level form alternation, one token per arm', () => {
		const hex = seq(choice(S('0x'), S('0X')), P('[0-9a-f]+'));
		const dec = choice(seq(P('\\d+'), S('.'), P('\\d+')), P('\\d+'));
		const rule = token(choice(hex, dec));
		expect(shape(distributeTokenForms(rule, 'number'))).toEqual(shape(choice(token(hex), token(dec))));
	});
	it('distributes the enclosing seq over an alternation at an inner position and keeps the wrapper kind', () => {
		const rule = immediate(seq(S('\\'), choice(P('u[0-9a-f]{4}'), P('x[0-9a-f]{2}'))));
		expect(shape(distributeTokenForms(rule, 'escape'))).toEqual(
			shape(choice(immediate(seq(S('\\'), P('u[0-9a-f]{4}'))), immediate(seq(S('\\'), P('x[0-9a-f]{2}')))))
		);
	});
	it('a form alternation under a presence choice hoists with the blank as an arm', () => {
		const rule = token(seq(S("'"), choice(choice(seq(S('\\'), P('.')), P("[^']")), BLANK), S("'")));
		expect(shape(distributeTokenForms(rule, 'char'))).toEqual(
			shape(
				choice(
					token(seq(S("'"), seq(S('\\'), P('.')), S("'"))),
					token(seq(S("'"), P("[^']"), S("'"))),
					token(seq(S("'"), S("'")))
				)
			)
		);
	});
	it('does not descend into an arm that is itself an alternation', () => {
		const dec = choice(seq(P('\\d+'), S('.')), P('\\d+'));
		const out = distributeTokenForms(token(choice(P('[a-z]+'), dec)), 'demo') as unknown as { members: RuntimeRule[] };
		expect(shape(out.members[1])).toEqual(shape(token(dec)));
	});
	it('keeps the prec stack around the distributed choice', () => {
		const rule = prec(3, token(choice(P('a+'), seq(S('b'), P('c+')))));
		const out = distributeTokenForms(rule, 'demo') as unknown as { type: string; value: number; content: { type: string } };

		expect(out.value).toBe(3);
		expect(out.content.type).toBe('CHOICE');
	});

	});
	it('throws when two arms are identical', () => {
		const arm = seq(S('0x'), P('[0-9a-f]+'));
		expect(() => distributeTokenForms(token(choice(arm, seq(S('0x'), P('[0-9a-f]+')))), 'demo')).toThrow(
			/token forms: arms 0 and 1 of 'demo' are identical/
		);
	});
});
```

```ts
// packages/codegen/src/dsl/transform/token-forms.ts
import {
	contentOf,
	isChoiceType,
	isPrecWrapper,
	isSeqType,
	matchesEmpty,
	membersOf,
	type RuntimeRule
} from '../../types/runtime-shapes.ts';

export type TokenChoiceClass = 'presence' | 'spelling' | 'forms';

type Typed = { type?: string; members?: RuntimeRule[]; content?: RuntimeRule; value?: unknown };

const typeOf = (rule: RuntimeRule): string => (rule as Typed).type ?? '';
const isBlank = (rule: RuntimeRule): boolean => typeOf(rule) === 'BLANK';
const isString = (rule: RuntimeRule): boolean => typeOf(rule) === 'STRING';

export function isTokenWrapper(rule: RuntimeRule): boolean {
	const t = typeOf(rule);
	return t === 'TOKEN' || t === 'IMMEDIATE_TOKEN';
}

export function classifyTokenChoice(choice: RuntimeRule): TokenChoiceClass {
	const arms = membersOf(choice);
	if (arms.some(isBlank)) return 'presence';
	if (arms.every(isString)) return 'spelling';
	return 'forms';
}

type Site = { readonly path: readonly number[]; readonly arms: readonly RuntimeRule[] };

function findOutermostForms(rule: RuntimeRule, path: readonly number[]): Site | undefined {
	const t = typeOf(rule);
	if (isChoiceType(t)) {
		const cls = classifyTokenChoice(rule);
		if (cls === 'forms') return { path, arms: membersOf(rule) };
		if (cls === 'spelling') return undefined;
		const live = membersOf(rule).filter((m) => !isBlank(m));
		if (live.length === 1 && isChoiceType(typeOf(live[0]!)) && classifyTokenChoice(live[0]!) === 'forms') {
			return { path, arms: [...membersOf(live[0]!), membersOf(rule).find(isBlank)!] };
		}
		return undefined;
	}
	if (isSeqType(t)) {
		const members = membersOf(rule);
		for (let i = 0; i < members.length; i++) {
			const found = findOutermostForms(members[i]!, [...path, i]);
			if (found) return found;
		}
		return undefined;
	}
	if ('content' in (rule as Typed) && (rule as Typed).content !== undefined) {
		return findOutermostForms((rule as Typed).content!, [...path, 0]);
	}
	return undefined;
}

function replaceAt(rule: RuntimeRule, path: readonly number[], arm: RuntimeRule): RuntimeRule {
	if (path.length === 0) return arm;
	const [head, ...rest] = path;
	const r = rule as Typed;
	if (Array.isArray(r.members)) {
		const members = r.members.map((m, i) => (i === head ? replaceAt(m, rest, arm) : m));
		return { ...(rule as object), members } as RuntimeRule;
	}
	return { ...(rule as object), content: replaceAt(r.content!, rest, arm) } as RuntimeRule;
}

function dropAt(rule: RuntimeRule, path: readonly number[]): RuntimeRule {
	const [head, ...rest] = path;
	const r = rule as Typed;
	if (rest.length === 0) {
		if (!Array.isArray(r.members)) return { type: 'SEQ', members: [] } as unknown as RuntimeRule;
		return { ...(rule as object), members: r.members.filter((_, i) => i !== head) } as RuntimeRule;
	}
	if (Array.isArray(r.members)) {
		return { ...(rule as object), members: r.members.map((m, i) => (i === head ? dropAt(m, rest) : m)) } as RuntimeRule;
	}
	return { ...(rule as object), content: dropAt(r.content!, rest) } as RuntimeRule;
}

const canonical = (rule: RuntimeRule): string =>
	JSON.stringify(rule, (key, value: unknown) => (key === 'id' || key === 'metadata' ? undefined : value));

export function distributeTokenForms(rule: RuntimeRule, kind: string): RuntimeRule {
	const precStack: RuntimeRule[] = [];
	let core = rule;
	while (isPrecWrapper(core as { type: string })) {
		precStack.push(core);
		core = contentOf(core);
	}
	if (!isTokenWrapper(core)) return rule;
	const body = (core as Typed).content!;
	const site = findOutermostForms(body, []);
	if (site === undefined) return rule;

	const arms = site.arms.map((arm) => (isBlank(arm) ? dropAt(body, site.path) : replaceAt(body, site.path, arm)));
	const empty = arms.findIndex(matchesEmpty);
	if (empty >= 0) throw new Error(`token forms: arm ${empty} of '${kind}' matches the empty string`);
	const seen = new Map<string, number>();
	arms.forEach((arm, i) => {
		const key = canonical(arm);
		const prior = seen.get(key);
		if (prior !== undefined) throw new Error(`token forms: arms ${prior} and ${i} of '${kind}' are identical`);
		seen.set(key, i);
	});

	let out: RuntimeRule = {
		type: 'CHOICE',
		members: arms.map((arm) => ({ ...(core as object), content: arm }))
	} as unknown as RuntimeRule;
	for (let i = precStack.length - 1; i >= 0; i--) out = { ...(precStack[i] as object), content: out } as RuntimeRule;
	return out;
}
```

```markdown
### `packages/codegen/src/dsl/transform/token-forms.ts::classifyTokenChoice`

What a choice under a token is, by its arms: `presence` when an arm is blank, `spelling` when every arm is a string literal, `forms` otherwise. Only `forms` hoists; the other two are what the token-interior pass seats as a flag or an enum slot.

### `packages/codegen/src/dsl/transform/token-forms.ts::distributeTokenForms`

The rule algebra behind the token-form hoist. For a rule whose prec-peeled core is a `TOKEN` or `IMMEDIATE_TOKEN`, finds the outermost form alternation on any path from the token root (descending through seqs and through a presence choice whose live arm is a form alternation, in which case the blank is one more arm) and distributes the whole token body over the arms: each arm becomes its own token of the same wrapper kind with the surrounding structure kept, and the result is a `CHOICE` of those tokens under the original prec stack. An arm that is itself an alternation is not descended into; it stays one lexeme. Two hazards are diagnostics: an arm that matches the empty string, and two arms with identical bodies. Any other rule shape is returned as is.
```

```ts
function hoistTokenForms(
	parentKind: string,
	rule: Rule,
	rulesBag: Record<string, Rule>,
	clauseGroupRules: Record<string, Rule>,
	groupDedupeMap: Record<string, string>,
	counter: ClauseHoistCounter,
	visibleGroupSources: Set<string>,
	clauseGroupOwners: Map<string, string>
): { rule: Rule; hoisted: boolean } {
	const distributed = distributeTokenForms(rule as unknown as RuntimeRule, parentKind) as unknown as Rule;
	if (distributed === rule) return { rule, hoisted: false };
	const precStack: Rule[] = [];
	let core = distributed;
	while (isPrecWrapper(core as { type: string })) {
		precStack.push(core);
		core = (core as { content: Rule }).content;
	}
	const arms = (core as { members: Rule[] }).members;
	const names = ((rule as { annotations?: { tokenFormNames?: Record<number, string> } }).annotations?.tokenFormNames ?? {}) as Record<number, string>;
	for (const key of Object.keys(names)) {
		const index = Number(key);
		if (index < 0 || index >= arms.length) {
			throw new Error(`variant() at '${key}' on '${parentKind}': the token distributes into ${arms.length} form(s)`);
		}
	}
	const members = arms.map((arm, i) => {
		const body = withHoistedAnnotation(arm);
		const named = names[i];
		let minted: string | null;
		if (named !== undefined) {
			minted = `${parentKind.replace(/^_+/, '')}_${named}`;
			if (minted in rulesBag || minted in clauseGroupRules) {
				throw new Error(`token forms: '${parentKind}' would mint '${minted}' but that rule already exists`);
			}
			clauseGroupRules[minted] = body;
		} else {
			minted = visibleGroupSynthName(body, parentKind, groupDedupeMap, counter, rulesBag, clauseGroupRules, undefined, undefined, 'arm');
			if (minted === null) throw new Error(`token forms: '${parentKind}' could not mint arm ${i}`);
		}
		visibleGroupSources.add(minted);
		if (!clauseGroupOwners.has(minted)) clauseGroupOwners.set(minted, parentKind);
		return { type: 'SYMBOL', name: minted } as unknown as Rule;
	});
	let out: Rule = { ...(core as object), members } as Rule;
	for (let i = precStack.length - 1; i >= 0; i--) out = { ...(precStack[i] as object), content: out } as Rule;
	return { rule: out, hoisted: true };
}

function addSupertypes(result: Record<string, unknown>, names: readonly string[]): void {
	if (names.length === 0) return;

}
```
