# Archive

Specs, plans, ADRs, handoffs and working notes that no longer describe the
code. They're kept for their reasoning and history, not maintained: names,
APIs and links inside them may be out of date or no longer resolve.

The layout mirrors where each file used to live: `superpowers/specs`,
`superpowers/plans`, `superpowers/handoffs` and `adr` come from under
`docs/`, and `root/` holds notes that sat at the repository root.

Current documentation starts at the [README](../../README.md), the
[codegen glossary](../compiler-phase-glossary.md) and
[DEVELOPMENT.md](../../DEVELOPMENT.md).
